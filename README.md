# Engineering AI Copilot

An AI-powered Retrieval-Augmented Generation (RAG) assistant for mechanical engineers.

## Features

- Upload engineering PDFs
- Automatically extract and chunk documents
- Store knowledge in a vector database
- Retrieve relevant engineering information using semantic search
- Generate accurate answers with OpenAI models

## Tech Stack

- Python
- OpenAI API
- ChromaDB
- Streamlit
- PyPDF
- Git/GitHub
